# time-utils

Centralized RDK repository for time management utilities. This repository serves as the single location for adding, managing, and documenting time-related libraries and tools for RDK devices and build environments.

## Components

| Component | Description |
|---|---|
| [`libchronyctl`](libchronyctl/README.md) | Lightweight C library for programmatic control of the `chronyd` NTP daemon over its Unix domain socket. |
